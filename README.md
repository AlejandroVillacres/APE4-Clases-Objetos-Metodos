# APE04: Clases, Objetos y Métodos

## Tema del Proyecto
Sistema básico de control de estudiantes y calificaciones para la asignatura de Algoritmos y Lógica de Programación.

## Integrante
- Alejandro Villacres

## Estructura del Repositorio
- **Cpp/**: Contiene el archivo fuente en C++ (`main.cpp`).
- **Java/**: Contiene los archivos fuente en Java (`Main.java`, `Estudiante.java`).
- **capturas/**: Carpeta destinada a las evidencias y capturas de ejecución de los programas.

## Requerimientos Cumplidos
1. Encapsulamiento mediante atributos privados y métodos de acceso (get/set).
2. Validación en el ingreso de calificaciones (rango estricto entre 0 y 10).
3. Cálculo automático del promedio.
4. Determinación automática del estado académico (Aprobado >= 7.00, caso contrario Reprobado).
5. Conteo final y listado completo de los estudiantes registrados.
